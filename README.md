## 📖 Sobre o projeto

A **PokéStock** é um sistema web desenvolvido para facilitar o gerenciamento do estoque de figuras colecionáveis de Pokémon, oferecendo uma solução prática, organizada e intuitiva para o controle de inventário.

A plataforma permite o cadastro, edição, remoção e consulta de produtos, possibilitando que os administradores acompanhem informações como nome, categoria, preço e quantidade disponível de cada item. Além disso, conta com ferramentas de pesquisa que tornam a localização dos produtos mais rápida e eficiente.

Com uma interface simples e de fácil utilização, o sistema foi desenvolvido para otimizar a administração do estoque, reduzindo erros no controle manual e proporcionando uma gestão mais organizada, seja para colecionadores ou para lojas especializadas em produtos Pokémon.

---

# ✨ Funcionalidades

## 📦 Gerenciamento de Estoque

- ➕ Cadastro de novas figuras colecionáveis.
- ✏️ Edição das informações dos produtos.
- ❌ Remoção de itens do estoque.
- 📋 Visualização completa do inventário.
- 🔍 Pesquisa de produtos por nome.
- 📊 Controle da quantidade disponível em estoque.
